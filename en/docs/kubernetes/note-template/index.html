This is an example page. It exists so you can see how the sidebar navigation, breadcrumbs, right-hand table of contents and prev/next links behave. Delete it once you write your first real note.

The problem

Describe the symptom as you actually saw it: the exact error message, what you were doing, and what you expected to happen.

Diagnosis

The steps you took to narrow down the cause. Code blocks are highlighted automatically:

kubectl get pods -A --field-selector=status.phase!=Running
kubectl describe pod <name> -n <namespace>

The fix

What actually fixed it, and why it worked.

What I’d do differently

The most valuable part of the note: what you learned for next time.
